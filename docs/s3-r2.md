# Amazon S3 and Cloudflare R2 in RCX

RCX uses rclone's **s3** backend for both Amazon S3 and Cloudflare R2.
This fork builds rclone **v1.75.2** for Android. Rebuild the native binaries
and APK; updating only the Gradle version string does not update installed RCX.

## Cloudflare R2

1. In the Cloudflare dashboard, create an R2 bucket and an R2 API token with
   **Object Read & Write** permission for the bucket. Record the Access Key
   ID, Secret Access Key, and Cloudflare **Account ID**. Do not use a global API key.
2. In RCX, choose **Add remote → Cloudflare R2**.
3. Enter a remote name (for example, r2), the R2 Access Key ID, Secret Access
   Key, and Cloudflare Account ID (not an endpoint URL).
4. Save the remote. RCX writes the equivalent of:

   ```ini
   [r2]
   type = s3
   provider = Cloudflare
   env_auth = false
   access_key_id = YOUR_ACCESS_KEY_ID
   secret_access_key = YOUR_SECRET_ACCESS_KEY
   region = auto
   endpoint = https://ACCOUNT_ID.r2.cloudflarestorage.com
   acl = private
   no_check_bucket = true
   ```

5. Open the bucket **inside** that remote (for example, r2:my-bucket) and use
   the existing **Upload** or Android **Share → RCX** action to send a file.

A bucket-scoped token might not permit *listing all buckets* at r2:. If RCX
requires listing bucket names from the remote root, grant the token the
appropriate listing permission. Object uploads to r2:my-bucket do not require
bucket creation because no_check_bucket is true.

## Amazon S3

Choose **Add remote → Amazon S3**. Enter the AWS Access Key ID, Secret Access
Key, and the bucket's AWS region (for example, ap-southeast-1). The remote
uses provider = AWS and env_auth = false, with AWS endpoint resolution.
Open an existing bucket and upload through RCX.

Use least-privilege credentials. Never commit real keys or rclone.conf to Git.

## Build and test

Requirements: Java 11, Go 1.26.9+, Git, Android SDK platform 30, and Android
NDK 28.2.13676358 (r28c). Run:

```sh
./gradlew rclone:buildNative
./gradlew testOssDebugUnitTest
./gradlew assembleOssDebug
```

The native executables are created in
app/lib/{armeabi-v7a,arm64-v8a,x86,x86_64}/librclone.so.
CI also builds them and publishes debug APK artifacts.

To verify real Cloudflare R2 operation, install the generated APK, configure
an R2 remote, open an existing bucket, upload a small file, and download it
back. These live tests require your own bucket and credentials and are not
executed by public CI.

Reference: https://developers.cloudflare.com/r2/examples/rclone/
