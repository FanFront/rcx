# RCX 简体中文使用指南

此分支已新增 **简体中文（zh-CN）** 界面，包含文件管理、上传/下载、
设置、远程存储配置及 Amazon S3 / Cloudflare R2 配置页面。

## 切换语言

1. 打开 RCX，进入 **Settings（设置）→ General（常规）→ Language（语言）**。
2. 选择 **简体中文** 并确认。
3. 完全关闭并重新启动 RCX，使新语言生效。

若 Android 系统语言已设为简体中文，且 RCX 中未指定其他语言，应用会自动使用简体中文。

## 上传文件到 Cloudflare R2

1. 在 Cloudflare 控制台创建一个 R2 存储桶，以及具有对象读写权限的 R2 API Token。
2. 记录三项信息：**账户 ID**、**访问密钥 ID**、**访问密钥（Secret）**。
3. 在 RCX 中选择 **添加远程存储 → Cloudflare R2**。
4. 填写远程存储名称、R2 访问密钥 ID、R2 访问密钥以及 Cloudflare 账户 ID。
5. 保存配置；RCX 将自动使用 S3 兼容后端，生成 R2 端点地址。
6. 打开相应存储桶，使用 **上传文件**，或从 Android 的文件分享菜单中选择 RCX 上传。

如果 Token 无权列举全部存储桶，从远程存储根目录可能无法显示桶列表。
使用已有存储桶并为 Token 授予适当的列举权限。请勿将真实密钥提交到 GitHub。

AWS S3 用户可以在 **添加远程存储 → Amazon S3** 中填写密钥和区域。

## 翻译与校验

- 中文 UI 文件：`app/src/main/res/values-zh-rCN/`
- 语言菜单：`app/src/main/res/values/arrays.xml`
- 检查资源格式：`python3 scripts/check_chinese_resources.py`
- 编译 APK：`./gradlew assembleOssDebug`（先构建 rclone 原生程序）

简体中文翻译参考了 [Jakeverse/rcx](https://github.com/Jakeverse/rcx)
的社区本地化资源，并在此基础上补充新的文本、S3/R2 和 UI 翻译；
保留原 RCX 的 GPLv3 许可证。
